# Gleap Desktop Wrapper

A Nativefier build script that opens the Gleap customer support dashboard in a desktop window. The repository includes the macOS icon and injected CSS used by the wrapper.

[Gleap](https://www.gleap.ai) · [Developer documentation](https://docs.gleap.ai/introduction)

## Build script

`build.sh` runs Nativefier against the Gleap dashboard and applies `site.css` and `macicon.png`. Install Nativefier separately before running the script.

The dashboard address in the script is an application endpoint. The website domain change does not change that endpoint.
